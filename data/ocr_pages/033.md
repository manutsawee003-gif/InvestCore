# เทคนิคการอ่าน งบกำไรขาดทุนเบ็ดเสร็จ

## วิเคราะห์กำไร จาก 4 อัตราส่วนทางการเงิน

### NPM Net Profit Margin = กำไรสุทธิ / รายได้

### ROA Return on Asset = กำไรสุทธิ / สินทรัพย์

### ROE Return on Equity = กำไรสุทธิ / ส่วนของเจ้าของ

### Q-E Quality of Earnings = กำไรสุทธิ / กระแสเงินสด จากการดำเนินงาน

## อัตราส่วนเหล่านี้ "ยิ่งสูง ยิ่งดี"

แสดงว่ากิจการมีความสามารถในการทำกำไรได้ดี

*   ขายสินค้าและบริการได้หรือไม่? รายได้เพิ่มขึ้นอย่างสม่ำเสมอหรือเปล่า?
    *   บริษัทสามารถควบคุมต้นทุนได้ดีหรือไม่? ดูได้จากอัตรากำไรสุทธิ (Net Profit Margin : NPM)
    *   ขนาดและการเติบโตของค่าใช้จ่ายต่าง ๆ เป็นอย่างไร? ส่งผลกระทบต่อกำไรในแต่ละขั้นอย่างไร?
    *   มีกำไรที่เป็นตัวเงินในทุกขั้นตอนหรือไม่? เพราะเหตุใด?
    *   กำไรสุทธิที่ได้มีคุณภาพหรือไม่? โดย **กำไรที่ดีต้อง...**

**cash**: เป็นเงินสด

**core**: เกิดจากธุรกิจหลัก **ไม่ใช่เกิดจากรายการอื่น เช่น กำไรจากการขายสินทรัพย์ หรือกำไรจากอัตราแลกเปลี่ยน

**Recurring**: เกิดซ้ำได้ ก๊าปเป็นกำไรที่เกิดจาก ธุรกิจหลัก จะสามารถเกิดซ้ำได้บ่อย ๆ

*   กำไรต่อหุ้นเพิ่มหรือลด? ถ้าลด ... ลดเพราะอะไร? ลดจากกำไรลด หรือลดจากเพิ่มทุน
