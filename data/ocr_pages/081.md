# เครื่องมือเพื่อป้องกันความเสี่ยง อัตราแลกเปลี่ยน

บังคับมีเครื่องมือบริหารความเสี่ยงจากอัตราแลกเปลี่ยนหลากหลายทางเลือก เช่น Futures, Forward และ Options

## การซื้อขาย Futures ที่อาจถึงอัตราแลกเปลี่ยนผ่านตลาดสัญญาซื้อขายล่วงหน้า TFEX

*   ปัจจุบันมีสินทรัพย์อย่างอิงทั้งหมด 3 ตู้สกุลเงิน คือ
    *   บาทต่อดอลลาร์สหรัฐ (USD Futures)
    *   ดอลลาร์สหรัฐต่อยูโร (EURUSD Futures)
    *   เยนต่อดอลลาร์สหรัฐ (USDJPY Futures)

การซื้อขาย Futures สามารถทำได้ เพียงมีบัญชีซื้อขายอนุพันธ์ และวางเงินหลักประกันประมาณ 2 - 3% ของมูลค่าสัญญา

&gt; **การใช้ Futures** ผ่านตลาดอนุพันธ์ เพื่อบริหารความเสี่ยง จากอัตราแลกเปลี่ยน จะช่วยลดความเสี่ยง ที่เกิดจากการเคลื่อนไหวของ อัตราแลกเปลี่ยนได้

## การทำธุรกรรม Forwards และ Options กับธนาคารพาณิชย์

จะต้องแสดงข้อมูลธุรกรรมการรับและจ่ายเงินต่อดอลลาร์สหรัฐในอนาคต เพื่ออนุมัติวงเงินกับทางธนาคาร ซึ่งจะเหมาะกับนักลงทุนรายใหญ่

### เงินบาทแข็งค่า

#### ตัวอย่าง การป้องกันความเสี่ยงค่าเงินโดยใช้ Futures

ปัจจุบัน $1 = ₿33

| | |
| :--- | ---: |
| **ลงทุนจริง** | **Futures** |
| ลงทุนในหุ้น A $100,000 | เปิดสถานะ Short USD Futures $100,000 |
| มูลค่าพอร์ต = $100,000 x B33 | ที่ USDTHB = B33 |
| = ₿3,300,000 | |

ต่อมา เงินบาทแข็งค่า $1 = ₿32

| | |
| :--- | ---: |
| **มูลค่าพอร์ต** | **ปิดสถานะ Short USD Futures** |
| = $100,000 x ₿32 | ที่ USDTHB = ₿33 |
| = ₿3,200,000 | **มูลค่าสัญญา** |
| **ขาดทุน** | **กำไร** |
| จากอัตราแลกเปลี่ยน - ₿100,000 | จากสัญญา Futures + ₿100,000 |
| **กำไร / ขาดทุน รวมทั้งหมด : 0** | |

จากตัวอย่าง การแข็งค่าของอัตราแลกเปลี่ยนเงินบาทต่อดอลลาร์สหรัฐ จะทำให้มูลค่าพอร์ตลงทุนในรูปสกุลเงินบาทลดลง แต่มีกลงทุนสามารถนำกำไรจากการ Short USD Futures มาชดเชยวูลค่าพอร์ตที่ลดลงไปได้
