### ดูหุ้นถูก หุ้นแพงด้วย อัตราส่วนราคาตลาดต่อกำไรต่อหุ้น

P/E* = \frac{ราคาตลาดต่อหุ้น}{กำไรสุทธิต่อหุ้น}

แสดงให้เห็นว่า... นักลงทุนยินดีจะจ่ายเงินซื้อหุ้นนั้น เป็นกี่เท่าของกำไรสุทธิของกิจการ หรือแปลได้ว่า หากกิจการนั้นมีกำไรต่อหุ้นคงที่ไปเรื่อยๆ การลงทุนหุ้นตัวนั้นจะใช้เวลากี่ปีในการคืนทุน

\* Price to Earnings per Share

แต่การดูคำ P/E เพียงอย่างเดียวอาจยังบอกไม่ได้ว่าหุ้นนั้นถูกหรือแพง ต้องมีการเปรียบเทียบกับ P/E ในอดีตของหุ้นตัวนั้น หรือ P/E ของอุตสาหกรรม หรือ P/E ตลาด เสมอ

#### ตัวอย่าง กิจการ A และ B เป็นกิจการอยู่ใน อุตสาหกรรมเดียวกัน ค่าเฉลี่ย P/E ของอุตสาหกรรม = 20 เท่า

| | |
| :--- | ---: |
| **หุ้น A**<br/>ราคาตลาด 10 บาท<br/>กำไรสุทธิต่อหุ้น 0.1 บาท | **หุ้น B**<br/>ราคาตลาด 200 บาท<br/>กำไรสุทธิต่อหุ้น 20 บาท |

| | |
| :--- | ---: |
| P/E Ratio = $\frac{10}{0.1} = 100$ เท่า | P/E Ratio = $\frac{200}{20} = 10$ เท่า |

| | |
| :--- | ---: |
| ราคาหุ้น A &lt; หุ้น B แต่ค่า P/E สูงกว่า หุ้น B และสูงกว่าอุตสาหกรรม | ราคาหุ้น B &gt; หุ้น A แต่ค่า P/E ต่ำกว่า หุ้น A และต่ำกว่าอุตสาหกรรม |

&gt; *ควรพิจารณาพื้นฐานของธุรกิจและแนวโน้มการเจริญเติบโตในอนาคตประกอบการตัดสินใจลงทุนด้วย
